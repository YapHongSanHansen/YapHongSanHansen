## Featured project

### [SONAR: behavioural security for Solana](https://github.com/Eriol-0406/Sonar-Dev3pack-V1)

Most crypto security tools fail because people click straight past the warning. SONAR targets the psychology instead. When a transaction looks risky, it forces a cooldown before signing, and an AI voice agent walks the user through the specific risks it found, such as a brand-new wallet, scam reports against the counterparty, or a freshly registered domain.

SONAR placed 3rd in Malaysia at Dev3pack and was selected for the Dev3pack Accelerator Programme.

[Live demo](https://sonar-dev3pack-v1.vercel.app) · [Repository](https://github.com/Eriol-0406/Sonar-Dev3pack-V1)
